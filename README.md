# README

- This repository contains the source code to simulate the Buckling-Free Low-Prestressed Self-Centering Brace (BF-LPSC Brace).

- lib includes contains a brace class, a material class and several class and functions to set up parameters for the OpenSees simulations and plots.

- 0_single_brace_simu.py: This script simulates the behavior of a single BF-LPSC brace under cyclic loading conditions. It utilizes the OpenSees framework to model the brace's response and analyze its performance.

- 1_.* files plot the total hysteresis curves.

- 2_.* files plot the curves of the ratchet part of the brace.
